 General                                                                                                                       
                  Enable static analysis information                                                  No                       If "Yes" is selected, compulsorily changes the build tool settings to acquire static analysis information.                   Enable dynamic analysis information                                                 No                       If "Yes" is selected, compulsorily changes the debug tool settings to acquire dynamic analysis information.                   Accumulate result of analysis                                                       No                       Specify whether to accumulate the result of analysis.

                  Display the SFR / IOR                                                               No                       Specify whether to display the SFR / IOR with the Variable List panel.

                  Frees memory of host machine when all panels are closed                             No                       Select whether to free memory of host machine or not when all panels of program analyzer are closed.CS+ can use memory of host machine efficiently when “Yes” is selected. But if memory of host machine is freed, it will take time to open a panel of program analyzer next time.
                  Ask whether cancel the result of analysis or not when out of memory error occurred  Yes                      Selects whether to show the confirmation dialog is displayed or not when out of memory error occurred during analyze.
